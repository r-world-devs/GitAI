# Set GitHub repositories in `GitAI` object.

Set GitHub repositories in `GitAI` object.

## Usage

``` r
set_github_repos(gitai, ..., verbose = is_verbose())
```

## Arguments

- gitai:

  A `GitAI` object.

- ...:

  Parameters to pass to
  [`set_github_host`](https://r-world-devs.github.io/GitStats/reference/set_github_host.html)
  function.

- verbose:

  A logical. If `FALSE` you won't be getting additional diagnostic
  messages.

## Value

A `GitAI` object.
