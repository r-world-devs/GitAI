# Run LLM on `GitAI` repositories content

Run LLM on `GitAI` repositories content

## Usage

``` r
process_repos(gitai, depth = 1, verbose = is_verbose())
```

## Arguments

- gitai:

  A `GitAI` object.

- depth:

  A numeric, maximum depth of folders to process.

- verbose:

  A logical. If `FALSE` you won't be getting additional diagnostic
  messages.

## Value

A list.
